# Archived Default Agent Profile

Archived date: 2026-05-22
Source: `.agents/agents/default-agent.md` active snapshot

## Former Role and Workflow

The default agent maintained project context, memory, logs, learnings, and archives. It read active context files before work; updated the relevant active files after meaningful work; archived older material before deleting it; preserved concise summaries and relative links; and never recorded secrets, API keys, passwords, tokens, private keys, or credentials.

The documented workflow was:

1. Read active context files.
2. Perform the requested task.
3. Update logs.
4. Update memory, learnings, and context when relevant.
5. Archive old material when needed.
6. Update indexes.

## Historical Project Context

The project was described as a Tauri 2/Rust Google Chat wrapper with a Safari-like user agent, Google Chat icon assets, runtime icon switching, app-managed Workspace windows, and a macOS app bundle.
